## Before you start (developer)
1. Join the Apple Developer Program.
2. Create a "Developer ID Application" certificate (Xcode → Settings → Accounts → Manage Certificates, or the developer website). Keep the exported `.p12` and its password outside the repository.
3. Create an app-specific password for your Apple ID, or an App Store Connect API key for notarization (the agent will explain which the installed Tauri version supports best).

## Goal
A universal `.dmg` that opens on any Mac without security warnings, built locally or in CI.

## Tasks
1. Read Tauri's macOS code signing and notarization guide for the installed version. List the exact environment variables it uses.
2. Hardened runtime on. Entitlements file with only what is needed: network server and client. Decide on App Sandbox: explain to the developer that sandboxing affects writing backups to pen drives and Keychain access, and recommend **no sandbox** for Developer ID distribution unless every feature is proven to work sandboxed. Record the decision as D26 after approval.
3. Info.plist keys from P7.2 are present in the signed app.
4. Local signing: `npm run tauri build -- --target universal-apple-darwin` with the variables set from the developer's Keychain; notarize; staple; verify with `spctl --assess --type open --context context:primary-signature -v` on the .dmg and `codesign --verify --deep --strict` on the app (check the right verification commands in Apple's documentation).
5. CI: job on `macos-latest` for version tags: import the certificate from base64 secret into a temporary keychain, build universal, notarize, staple, upload the `.dmg`. Delete the temporary keychain at the end even on failure.
6. `RELEASE.md` macOS section: creating certificates, secrets to add, how to rotate them.
7. Test: the notarized .dmg downloaded through a browser (so it is quarantined) opens on a Mac that has never run Vidya; local network permission prompt appears with the right text; data folder survives replacing the app with a newer version.

## Done when (agent)
- [ ] CI notarized build works on a test tag (e.g. `v0.9.0-rc1`)

## Done when (developer)
- [ ] Download the CI `.dmg` in Safari, open it, drag to Applications, open Vidya: no "cannot be opened" warning
